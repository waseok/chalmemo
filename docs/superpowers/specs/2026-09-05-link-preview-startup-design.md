# Memo 링크 카드 및 시작 동작 설계

## 목표

1. URL을 붙여넣거나 전역 단축키로 가져오면 페이지 제목과 도메인이 포함된 링크 카드로 표시한다.
2. Windows 로그인 시 Memo를 자동 실행하되 창은 보이지 않고 트레이에 상주한다.
3. `Ctrl+Alt+M`으로 선택 내용을 캡처한 뒤 Memo 창을 표시하고 활성화한다.
4. 모든 메모 데이터와 설정은 로컬에만 저장하며 별도 서버를 사용하지 않는다.

## 링크 카드

- `http://` 또는 `https://` 단일 URL을 감지한다.
- Rust 명령이 페이지를 최대 3초 동안 직접 조회한다.
- HTML 응답은 최대 512KB까지만 읽고 `<title>`을 추출한다.
- URL의 호스트 이름을 도메인으로 표시한다.
- 결과는 TipTap `linkCard` 노드로 저장한다.
- 카드에는 페이지 제목, 도메인, 원본 URL을 저장하며 클릭하면 기본 브라우저로 연다.
- 제목 조회 실패 시 도메인을 제목으로 사용하므로 붙여넣기 자체는 실패하지 않는다.
- 로컬 주소, 파일 URL, 사용자 정보가 포함된 URL은 조회하지 않고 URL 정보만 표시한다.

## 시작 및 창 동작

- 설치 후 기본 설정은 Windows 로그인 시 자동 실행 ON이다.
- 자동 실행 인수로 `--hidden`을 전달한다.
- `--hidden`으로 실행되면 메인 창을 생성하되 즉시 숨기고 트레이에 상주한다.
- 사용자가 창의 닫기 버튼을 누르면 종료하지 않고 트레이로 숨긴다.
- 완전 종료는 트레이의 `종료` 메뉴로만 수행한다.
- 전역 단축키 캡처가 성공하면 숨겨진 창을 표시하고 포커스를 준다.
- 캡처 실패 시에도 앱은 멈추지 않으며 창을 표시해 오류 상태를 알린다.

## 데이터 흐름

1. 외부 앱에서 텍스트/URL 선택
2. `Ctrl+Alt+M` 입력
3. 백그라운드 캡처 작업이 선택 내용을 클립보드로 복사
4. 일반 텍스트는 현재 탭에 삽입
5. 단일 URL은 Rust에서 제목·도메인을 조회
6. TipTap 링크 카드로 삽입
7. Memo 창 표시 및 활성화
8. 기존 로컬 자동 저장 경로에 저장

## 오류 처리

- 네트워크 실패, 비 HTML 응답, 제목 없음: 도메인 기반 카드로 대체
- 요청 시간 초과: 3초 후 대체 카드
- 응답 과다: 512KB에서 중단
- 잘못된 URL: 기존 일반 텍스트로 삽입
- 전역 단축키 중복 입력: 기존 디바운스와 단일 작업 잠금 유지

## 검증

- 제목이 있는 공개 URL → 제목·도메인 카드
- 연결 실패 URL → 도메인 대체 카드
- 일반 문장 안 URL → 기존 텍스트 동작 유지
- Windows 자동 실행 설정 등록 및 `--hidden` 인수 확인
- 숨김 실행 시 창이 보이지 않고 트레이 프로세스가 동작
- 메모장, Excel, Edge에서 단축키 캡처 후 창 표시 및 1회 삽입
- 빌드, 린트, Rust/TypeScript 테스트 통과
